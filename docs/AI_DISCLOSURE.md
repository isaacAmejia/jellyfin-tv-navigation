# AI Disclosure

## This project was built using AI

**The entire project was built using AI.**

All source code and repository documentation were generated and iteratively developed with **OpenAI ChatGPT**. The human project owner supplied the goals, environment, requirements, diagnostic output, testing feedback, and acceptance decisions, while the AI produced and revised the implementation and documentation.

This includes the final navigation script, development revisions, debugging changes, repository documentation, and the packaging/organization of this repository.

## Development process

The project was created through an iterative human-in-the-loop workflow:

1. The project owner described desired Jellyfin TV behavior and the actual hardware/software environment.
2. AI-generated JavaScript implementations were tested on the real client.
3. The project owner reported failures, regressions, UI behavior, console output, and successful behavior.
4. The AI inspected relevant source code and diagnostics, then generated revised implementations.
5. Known-good behavior was preserved while later issues were addressed.
6. The final r12.12 build was accepted after hands-on testing.

## What this disclosure means

AI-generated code can contain mistakes, incorrect assumptions, security issues, compatibility problems, or behavior that was not anticipated during testing. The presence of working behavior in the original environment does not guarantee that the code is correct for every Jellyfin installation.

Anyone using or modifying this project should review the code and test it in their own environment.
